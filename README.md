# AI CV Analyzer

AI-powered resume analysis tool that helps users improve their CVs through ATS scoring, skill analysis, and personalized recommendations.

## Features

- Upload resumes in PDF or DOCX format
- ATS score analysis
- Skill and keyword gap detection
- AI-generated resume improvements
- Download improved resumes as PDF
- Career assistant chatbot
- Authentication and user dashboard

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL

### AI
- OpenAI
- LM Studio (optional)

## Getting Started

### Build via docker

```bash
docker compose up -d --build
```

Now open the below URL in any browser
```bash
http://localhost:3001
```
